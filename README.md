# 🌐 WebsiteHub

WebsiteHub is a web-based platform for discovering and requesting professional website designs.

## 🚀 Features

- 🏠 Modern home page
- 🌐 Website template marketplace
- 🔎 Website search and categories
- 🎨 Multiple website designs
- 📩 Customer website request form
- 🗄️ MySQL customer database
- 👨‍💼 Admin login
- 📊 CRM dashboard
- 👤 Customer details management
- ✏️ Edit customer information
- 🔄 Customer status tracking
- 🗑️ Delete customer requests
- 📧 Email notifications
- 📱 Responsive design
- 🎯 Demo websites

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL
- Git & GitHub
